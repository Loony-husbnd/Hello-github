# 폴더 가드 (FolderGuard)

갤럭시 폴더2용 경량 보안 앱이다. 잠금화면(패턴/PIN/비밀번호) 인증을 5회 이상 실패하면
알람 스트림으로 최대 음량 사이렌을 울리고, 셀카 카메라로 사진 5장을 연속 촬영한다.

## 설치 방법
1. GitHub 저장소의 Actions 탭 → "Build FolderGuard APK" → 최신 실행의 `FolderGuard-debug-apk` 다운로드.
2. APK를 폰으로 옮겨 설치(설정에서 "출처를 알 수 없는 앱" 허용 필요).
3. 앱 실행 후 ① 기기 관리자 켜기 ② 카메라 권한 허용 ③ 테스트로 동작 확인.

## 최적화 / 배터리
- 상시 실행 서비스 없음. 시스템이 `onPasswordFailed`를 호출할 때만 프로세스가 깨어난다(평소 배터리 소모 0에 가깝다).
- 외부 라이브러리 없음, UI는 코드로 구성(리소스 최소).
- 사이렌은 2초 파형을 1회 생성 후 MODE_STATIC 반복 재생(CPU 부하 최소), 최대 60초 후 자동 종료, 잠금 해제 성공 시 즉시 종료.
- 카메라는 프리뷰 없이 Camera1 API, 약 1MP 해상도, 촬영 후 즉시 해제. 사진은 앱 내부 저장소에 최대 50장 유지.

## 한계
- 기기 관리자를 해제하거나 앱을 삭제하면 동작하지 않는다(설정 > 보안에서 가능).
- 방해금지 "알람 허용 안 함/완전 무음" 설정에서는 알람음이 차단될 수 있다. 일반 무음/진동 모드에서는 울린다.
- 안드로이드 9 이상 기기에서는 백그라운드 카메라 제한으로 촬영이 실패할 수 있다(폴더2의 안드로이드 6~7 기준으로 설계).
