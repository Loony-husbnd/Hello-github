# 폴더 가드 탭 (FolderGuardTab)

갤럭시 탭 S6 Lite(안드로이드 10~14)용 버전이다. 잠금화면 인증을 5회 이상 실패하면 사이렌을 울리고 셀카 사진 5장을 연속 촬영한다.

## 폴더2 버전과 다른 점
안드로이드 10 이상은 백그라운드 앱의 카메라 사용을 막는다. 그래서 사이렌은 수신기에서 즉시 울리고,
카메라는 검은 화면의 `AlarmActivity`를 잠금화면 위에 잠깐 띄워 촬영한 뒤 닫는 방식을 쓴다.
이 화면을 띄우려면 다음 권한이 필요하다(앱 안 버튼으로 이동 가능).
1. 기기 관리자, 2. 카메라·알림, 3. 다른 앱 위에 표시, 4. 전체화면 알림(안드로이드 14).

## 배터리
상시 서비스가 없고, 실패 이벤트 때만 동작하며 최대 60초 후 종료된다. 잠금 해제 성공 시 즉시 중지된다.

## 한계
- 실제 기기 검증은 하지 못했다. 삼성 One UI의 정책에 따라 화면 띄우기가 막히면 사이렌만 울릴 수 있다.
- 기기 관리자 해제/앱 삭제 시 작동하지 않는다. 방해금지 "완전 무음"에서는 알람음이 막힐 수 있다.
